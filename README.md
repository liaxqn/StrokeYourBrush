# 🎨 StrokeYourBrush

**A browser-based digital drawing and frame-by-frame animation studio.**

StrokeYourBrush is a creative web application that lets users draw, experiment with expressive brushes, and turn their sketches into simple animations — all directly in their browser, without needing an account.

## ✨ Features

### 🖌️ Digital Drawing
- Draw using a mouse, stylus, or touchscreen.
- Multiple brushes, including Loose Ink, Soft Pencil, Neon Glow, and Rainbow Ribbon.
- Customizable brush size and colour selection.
- Colour wheel and saved colour palette.
- Canvas backgrounds, including paper, grid, and gradient styles.
- Brush, Eraser, and Lasso tools.
- Undo and redo functionality.
- Zoom, duplicate, and move selected marks.

### 🎞️ Frame-by-Frame Animation
- Create animations using individual frames.
- Add and delete frames.
- Play and pause animation previews.
- Adjust playback speed from 1–30 FPS.
- Onion skinning to reference the previous frame while drawing.
- Export animations as WebM videos with adjustable durations.

### 💾 Save and Export
- Export drawings as PNG images.
- Save and reopen projects using JSON files.
- Download animated artwork.
- Work locally in the browser without creating an account.

### 📱 Responsive Design
- Designed for desktop, tablet, and mobile screens.
- Supports portrait and landscape layouts.

## ⚙️ How It Works

StrokeYourBrush combines an interactive drawing workspace with editing tools, animation controls, and export options.

1. **Drawing:** Users select a brush, choose a colour and size, and draw on the canvas.
2. **Editing:** Users refine their artwork with tools such as the eraser, lasso, undo, and redo.
3. **Animation:** Users create and manage frames, preview their sequence, and adjust the frame rate.
4. **Exporting:** Artwork can be downloaded as PNG, while project data can be saved and reopened using JSON files. Animations can be exported as WebM videos.

## 🚀 Development

StrokeYourBrush was developed using an AI-assisted coding workflow in Replit. The initial version was refined through multiple rounds of editing, testing, and debugging before being published as a web application.

This project provided an opportunity to explore interactive frontend development, drawing interfaces, animation workflows, and browser-based file exports.
